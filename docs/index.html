存链接、不丢失、真去读

🐱 鼠标移到刘海 → 📖 展开阅读列表 → 点链接就打开

✨ 功能

🎯

刘海交互

鼠标移到刘海区域自动展开，⌘⇧R 一键打开

🔗

一键保存

Chrome 扩展一键保存当前页面，自动抓取标题和摘要

📊

自动分组

按域名自动归类：GitHub、微信、Twitter……

🚦

陈旧提醒

<7天绿 · 7-30天黄 · >30天红

🔍

快速搜索

按标题、URL、域名搜索，秒找链接

🔒

隐私安全

数据纯本地存储，不联网，不收集任何信息

📥 三步安装

1

下载并解压

点击上方下载按钮，解压得到 Read It Later.app

2

移到应用程序文件夹

拖拽到 /Applications 或留在下载文件夹都可以

3

双击启动

没有任何窗口弹出是正常的。刘海区会出现 📖 图标，鼠标移过去就展开了

⚠️ 首次打开时，系统可能提示"无法验证开发者"。
前往 系统设置 → 隐私与安全性，往下翻到「安全性」区域，点击「仍要打开」。
